# Sustain Energy 

This is a basic, easy-to-read skeleton of the Sustain Energy website for the graded unit brief.
It shows where each required feature will live and includes simple styling and placeholder logic.

## Quick start (no coding needed)
1. Open `index.html` in a browser.
2. Use the navigation links to move between pages.
3. The Green Calculator saves totals to the Dashboard using local storage in your browser.

## What is included
- Registration, login, and password reset placeholders.
- Mission statement and sustainability description pages.
- User details page with example company data.
- Green Calculator with CRUD buttons and a points dashboard.
- Green Shop (shopping trolley) to purchase points.
- Feedback page to contact the administrator.
- Credentials section with custom logos.
- Gallery with sustainability themed images.
- Terms, privacy, and copyright information.
- View controls that let users resize text, change font, and adjust layout.

## Folder guide
- `index.html` and other `.html` files: Main website pages.
- `assets/css/styles.css`: Shared styling.
- `assets/js/app.js`: Shared JavaScript for view controls, calculator, dashboard, and shop.
- `assets/images/`: SVG images used across the site.
- `backend/`: Placeholder PHP endpoints for forms.
- `scripts/`: Example Python rubric calculator.
- `src/`: Example Java rubric calculator.
- `docs/`: Human-readable documentation.
- `CHANGELOG.md`: Recorded changes with dated entries from 27/04/2026.

## Notes
- This is a skeleton only; it can be extended with database storage and real authentication later.
- The rubric is a placeholder until the official "Sustainability Rubric INFORMATION - Graded Unit 2" is provided.
